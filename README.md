# Менеджер заметок на Kotlin

`Main.kt` содержит интерфейс консольного менеджера заметок на Kotlin. Командный интерфейс построен на Clikt. Kotlin Coroutines импортирован, но асинхронных операций в данном фрагменте пока нет.

## Структура

Точка входа объявляет команды для создания, просмотра, поиска, изменения, удаления и экспорта заметок. Обработчики сейчас выводят демонстрационные сообщения: сохранение, поиск, удаление и экспорт в файлы не реализованы. Для компиляции требуется проект Kotlin/JVM с подходящей версией Clikt; наличие импорта Coroutines также нужно учитывать. Репозиторий содержит пример CLI, а не готовый менеджер заметок.
