# Менеджер заметок на Kotlin

`Main.kt` содержит интерфейс консольного менеджера заметок на Kotlin. Команды построены на Clikt, выполнение асинхронных операций использует Kotlin Coroutines.

## Структура

Точка входа объявляет команды для создания, просмотра, поиска, изменения, удаления и экспорта заметок. Обработчики выводят демонстрационные сообщения. Для сборки требуется проект Kotlin/JVM с зависимостями Clikt и Kotlin Coroutines.
